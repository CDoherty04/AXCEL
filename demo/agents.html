Run an agent

        
Give it a task. It shops inside its mandate.

        
An OpenAI agent reads its mandate and buys through the same protocol path as any purchase. An out-of-mandate attempt is refused and scored; Revoke stops it for good.

Pay per use

        
HTTP 402, paid by voucher.

        
The agent reads the 402, pays only if the price fits its channel, and settlement releases RLUSD to the merchant. If an agent and a merchant are filled in above, the same voucher is anchored on XRPL and added to the score.
